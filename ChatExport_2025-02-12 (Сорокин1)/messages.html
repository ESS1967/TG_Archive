Настройка RDP (Удаленного рабочего стола) для многопользовательского доступа к кластеру на Windows Server 2019
Этот вариант позволяет нескольким пользователям одновременно работать в одном сеансе Windows Server 2019 с учетной записью кластера (Cluster_Login). Подразумевается, что сервер настроен как терминальный сервер (Remote Desktop Services, RDS).

✅ Плюсы:
Удобная среда для работы пользователей с ресурсами кластера.
Поддержка совместной работы (например, запуск программ, совместный доступ к файлам).
Высокий уровень безопасности при правильной настройке.
Гибкость (можно использовать группы AD или локальных пользователей).
❌ Минусы:
Требуются лицензии RDS CAL (по умолчанию Windows Server разрешает только 2 одновременных RDP-подключения).
Более высокая нагрузка на сервер (нужны достаточные CPU/RAM ресурсы).
Может потребоваться настройка групповой политики (GPO) для ограничения прав пользователей.
🚀 Пошаговая настройка RDP для многопользовательского доступа
Для полноценной работы необходимо развернуть службы удаленных рабочих столов (RDS) и правильно настроить сервер.

1️⃣ Включение удаленного доступа (RDP) на сервере
📌 Этот шаг позволяет пользователям вообще подключаться к серверу по RDP.

Откройте Server Manager (Диспетчер серверов).
Перейдите в Local Server -> Remote Desktop -> Enable.
Включите галочку Allow remote connections to this computer.
Убедитесь, что "Allow connections only from computers running Remote Desktop with Network Level Authentication" включено (это повышает безопасность).
📌 Проверяем сетевой доступ:

Откройте PowerShell и выполните команду:
powershell
Копировать
Редактировать
Get-NetFirewallRule -DisplayGroup "Remote Desktop" | Select DisplayName, Enabled
Если видите Enabled=False, включите его командой:
powershell
Копировать
Редактировать
Enable-NetFirewallRule -DisplayGroup "Remote Desktop"
2️⃣ Установка и настройка служб удаленных рабочих столов (RDS)
📌 Этот шаг позволяет серверу поддерживать более двух одновременных RDP-подключений.

Откройте Server Manager -> Manage -> Add Roles and Features.
Выберите Remote Desktop Services Installation.
Установите роли:
Remote Desktop Session Host (RDSH) – позволяет многопользовательский RDP-доступ.
Remote Desktop Licensing (RDL) – нужен для лицензирования пользователей.
Перезагрузите сервер после установки.
3️⃣ Настройка групп и учетных записей пользователей
📌 Мы создадим группу, добавим в нее пользователей и дадим ей доступ к RDP.

Откройте Server Manager -> Tools -> Computer Management.
Перейдите в Local Users and Groups -> Groups.
Найдите группу Remote Desktop Users.
Добавьте в нее:
Учетную запись кластера (Cluster_Login).
Всех сотрудников подразделения.
Готово! Теперь эти пользователи смогут подключаться к серверу.
📌 Если сервер находится в домене (AD), то можно добавить группу AD вместо отдельных пользователей.

4️⃣ Настройка RDP-лицензирования
📌 По умолчанию Windows Server позволяет только 2 одновременных RDP-подключения. Чтобы снять это ограничение, требуется лицензирование.

Установите Remote Desktop Licensing (RDL) (если не сделали ранее).
Откройте Server Manager -> Remote Desktop Services -> RD Licensing Manager.
Активируйте сервер лицензий.
Укажите тип лицензии:
Per User (по пользователям, если в компании используется AD).
Per Device (по устройствам, если учетные записи не фиксированные).
Введите ключи лицензий (RDS CALs).
📌 До активации лицензий сервер будет работать в пробном режиме 120 дней.

5️⃣ Ограничение доступа к сессиям и безопасности RDP
📌 Теперь мы ограничим количество сессий и улучшим безопасность.

gpedit.msc -> Computer Configuration -> Administrative Templates -> Windows Components -> Remote Desktop Services -> Remote Desktop Session Host -> Connections.
Включите параметр "Limit number of connections" и задайте, например, 5.

powershell
